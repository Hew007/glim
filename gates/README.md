# 验收门禁自检报告

每个里程碑结束时，在此目录下新建 `M0.md`、`M1.md` … 输出该阶段的门禁自检结果。

## 格式

| 编号 | 结果 | 实测数据 / 证据 |
|---|---|---|
| 0.1 | ✅ 通过 | p95 = 38ms（20 次采样，日志见 gates/M0-timing.log） |
| 0.2 | ❌ 未通过 | 窗口仍出现在 Alt+Tab，原因：漏加 WS_EX_TOOLWINDOW |

## 规则

- 性能类必须给**实测数字**，不接受「应该没问题」「基本达标」。
- 任一条未通过，停在当前里程碑修复，**不得进入下一阶段**。
- 不得为了通过门禁而放宽门禁。达不到就如实报告，附数据和原因分析。
- 截图、日志等证据文件放在本目录，已在 `.gitignore` 中排除，仅报告本身入库。

完整门禁清单见 [../docs/PLAN.md](../docs/PLAN.md) 第 8 节；审核流程见第 9 节。
