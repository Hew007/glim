# glim

[简体中文](#简体中文) | [English](#english)

## 简体中文

按一下，看一眼，走。glim 是一个 Windows 上的极简划词翻译与查词工具，用来快速查看选中文字的含义或译文。

当前仓库提供[许可文件](LICENSE)。源码与安装包尚未在本仓库发布。

## English

Press, glance, go. glim is a minimalist Windows utility for looking up and translating selected text.

The repository currently contains the [license](LICENSE). Source code and installers are not published here yet.
