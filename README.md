# Glim

**按一下，看一眼，走。**

Windows 上的极简翻译与查词工具。复制文本，按 `Ctrl+Alt+D`，结果出现在光标旁，看完按 Esc 消失。

> 🚧 开发中，尚无可用版本。当前处于 M0 阶段，进度见 [docs/PLAN.md](docs/PLAN.md)。

---

## 它是什么

一个常驻后台的小工具，专注做好一件事：把剪贴板里的东西快速翻译或查词。

- **零决策**。不用选引擎、不用选语言方向、不用理解 API。复制什么就翻什么，中英自动互译。
- **查词和翻译分开处理**。单词和短语出词典卡片（音标、词性、释义、常见搭配、例句），句子出流畅译文。`take off` 不会被逐词翻译。
- **不留痕**。不进任务栏、不进 Alt+Tab、不存历史、不发遥测。
- **不夺焦点**。弹窗出现时你的输入光标不会丢。

## 它不是什么

不是全功能翻译套件。没有 OCR、没有插件系统、没有主题、没有生词本。这些不在计划内，见 [推迟清单](docs/PLAN.md#11-明确推迟-v2)。

## 设计原则

冲突时按顺序取舍：

1. **快 > 全**。首屏出现速度优先于结果完整度。
2. **零决策**。复杂度藏在背后，用户只管复制和按键。
3. **不留痕**。用完即走，不占用注意力。

## 技术栈

Tauri v2 + React + TypeScript，Rust 处理热键、剪贴板、窗口与网络。

## 隐私

- API Key 存 Windows 凭据管理器，不落明文文件。
- 历史仅存内存，退出即失。
- 除翻译请求外不发起任何网络连接。无遥测、无崩溃上报。
- ⚠️ 使用 Gemini 免费层时，输入输出可能被 Google 用于改进产品。介意请升级到付费层或改用其他 Provider。
